Smart Tools

Four more data structures at work behind these tools

GPA Range Explorer — Binary Search Tree

Every student's GPA lives in a BST. Pick a range and the tree prunes whole branches instead of scanning every record.

Study Buddy Finder — Graph + BFS

Students sharing a subject and grade are connected in a graph. BFS finds peers within a chosen number of introductions.

Recently Viewed — LRU Cache, capacity 5

Opening a student's profile touches an LRU cache. The 6th view evicts whoever's been looked at least recently.

Find by Roll No. — Merge Sort + Binary Search

The roster is merge-sorted by roll number once, then searched in O(log n) instead of a linear scan.
